# ENKO Letter Prism

Интерактивный MVP генератора знаков для системы подбрендов ЭНКО.

Идея: пользователь вводит букву, генератор рисует ее в скрытом растровом слое, а затем дробит и преломляет через радиальную мозаичную сетку. На выходе получается квадратный знак 1:1: орнаментальный, звездоподобный, но все еще связанный с исходной буквой.

## Запуск

Откройте `index.html` в браузере.

## Что уже есть

- ввод одной буквы;
- выбор шрифтового характера;
- два режима рендера: растровые фрагменты или цельная заливка ячеек;
- радиальные секторы 4-16;
- преломление, смещение, плотность и читаемость;
- регулируемые промежутки между ячейками;
- вращение радиальных рядов относительно друг друга;
- отключаемый чертежный слой сетки;
- три цветовых режима;
- экспорт PNG;
- экспорт JSON с параметрами генерации.

## Быстрые направления

- Оп-арт диск: `Штриховая`, много секторов, высокая толщина рядов, сетка выключена.
- Галактическая буква: `Галактика`, 4-5 рядов, вращение рядов 30-70.
- Разорванные лучи: `Пульс`, низкое смешивание, сильное преломление.
- Форма из буквы: `Из буквы`, промежутки 12-24, вращение рядов 15-45.
- Каноничный знак: `Розетка`, `Закрашивать ячейки`, промежутки 8-18, порог заливки 10-24.
- Архитектурная мозаика: `Кирпичная`, сетка включена, умеренное вращение.
