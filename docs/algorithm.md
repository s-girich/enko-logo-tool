# Алгоритм

## MVP

```text
буква -> скрытая raster-маска -> анализ покрытия кольцевых ячеек -> SVG path -> квадратный векторный знак
```

Браузер рисует букву в скрытый canvas только для анализа. В каждой кольцевой ячейке берется регулярная выборка точек по радиусу и углу. Если среднее покрытие буквой выше заданного порога, ячейка становится непрозрачным SVG path. Видимый знак и основной экспорт полностью векторные.

Числовые параметры не имеют искусственных верхних и нижних границ в интерфейсе. При большом числе рядов их расчетная толщина пропорционально нормализуется в рабочий радиус знака. Интерфейс показывает общее число расчетных ячеек и число ячеек, геометрия которых сохраняется после применения промежутков.

## Квадратный калейдоскоп

```text
буква -> фрагмент-семя -> 4x/8x отражение -> модульная сетка -> словарь фигур -> цветной SVG
```

Координаты каждой итоговой ячейки складываются к центральному фрагменту исходной буквы. Для симметрии `4x` используются отражения по горизонтали и вертикали; для `8x` дополнительно складываются координаты относительно диагонали. Покрытые ячейки детерминированно превращаются в прямоугольники, круги, ромбы и четверти круга. Тип фигуры и цвет зависят от координат семени и покрытия, поэтому зеркальные пары совпадают, а разные буквы дают разные знаки.

## Радиальная эмблема

```text
буква -> две дорожки семени -> концентрические слои -> повторение по лепесткам -> цветной SVG
```

Каждый слой считывает покрытие в двух точках семени внутри содержательной области глифа. Активные дорожки повторяются по заданному числу лепестков и превращаются в круги, ромбы, вытянутые лепестки или радиальные перекладины. Цвет закреплен за слоем и дорожкой. Промежутки уменьшают размер модулей, не меняя радиус композиции.

## Модульный герб

```text
буква -> квадратное отраженное семя -> осевая классификация -> макромодули -> цветной SVG
```

Модульный герб использует ту же 4x/8x выборку, что квадратный калейдоскоп, но меняет словарь вывода. Ячейки вдоль горизонтальной и вертикальной осей становятся перекладинами, центральные ячейки - ромбами, диагональные - кругами и угловыми сегментами. Соседние перекладины могут визуально объединяться в крупные формы.

## Радиальный отпечаток

```text
буква -> серия лучевых сканов -> пересечения и заполненные интервалы -> профиль слоя -> повторение по лепесткам
```

Каждый луч регулярно считывает альфа-маску от центра к краю. Из последовательности вычисляются число заполненных сегментов, доля покрытия, первое и последнее пересечение, общий размах. Эти признаки определяют тип модуля, длину, ширину и наличие отверстия. Один профиль повторяется по всем лепесткам, поэтому чувствительность к букве повышается без потери строгой радиальной симметрии.

## Морфокалейдоскоп

```text
буква -> поле признаков -> симметричные орбиты ячеек -> морфологические стадии -> 4x/8x модульный знак
```

Для сетки считаются глубина активной ячейки, локальное направление и закрытые контрформы. Каждая выходная позиция анализирует полный набор соответствующих точек своей отраженной орбиты. Глубокие зоны становятся кругами и ромбами, направленные штрихи - радиальными и касательными перекладинами, контрформы - модулями с негативным центром.

## Герб-мандала

```text
буква -> морфологическое квадратное ядро + лучевой профиль -> согласованная центрально-радиальная эмблема
```

Внутренняя часть использует уменьшенный морфокалейдоскоп, внешняя - радиальный отпечаток с одной дорожкой на слой. Обе части получают данные из одной повернутой маски буквы и используют общие масштаб, порог и промежутки. Квадратное отражение управляет ядром, а число лепестков - внешним поясом.

## Тектоника

```text
буква -> карта покрытия -> жадное объединение соседних ячеек -> макрозоны -> цветной SVG
```

Активные ячейки без отражений объединяются в горизонтальные, вертикальные и квадратные зоны размером до трех ячеек. Зоны превращаются в плиты, капсулы, эллипсы и срезанные блоки. Порядок обхода и геометрия буквы детерминируют асимметричную композицию.

## Скелет

```text
буква -> карта покрытия -> поле расстояний -> локальные хребты -> связный граф -> цветной SVG
```

Для активных ячеек считается манхэттенское расстояние до пустоты. Локальные максимумы становятся узлами скелета, соседние узлы соединяются, а отдельные компоненты связываются кратчайшими возможными ребрами. Окончания становятся ромбами, пересечения - кругами, промежуточные узлы - повернутыми квадратами.

## Упаковка

```text
буква -> поле расстояний -> кандидаты по размеру -> исключение пересечений -> набор примитивов
```

Расстояние до пустоты задает максимально допустимый размер фигуры в каждой точке. Кандидаты сортируются по размеру и покрытию, после чего размещаются без пересечений до заданного максимума. Используются круги, квадраты и капсулы; их положение и поворот выводятся из координат карты, без случайности и отражений.

## Арматура

```text
буква -> карта покрытия -> анализ соседей -> направление локального штриха -> перекладины и узлы
```

Каждая активная ячейка сравнивает горизонтальные, вертикальные и диагональные пары соседей. Самое сильное направление становится вытянутой перекладиной; длина зависит от расстояния до края буквы. В местах пересечения направлений добавляются небольшие круги и ромбы. Цвет закреплен за направлением штриха.

## Изолинии

```text
буква -> карта покрытия -> поле расстояний -> уровни эрозии -> контурные SVG path
```

Из поля расстояний выбирается несколько равномерно распределенных порогов. Для каждого порога строится граница области, сохранившейся после виртуальной эрозии. Уровни получают разные цвета, а толщина линий и точность контура управляются существующими параметрами.

## Матрица

```text
буква -> карта покрытия -> объединение в макрозоны -> негативные вырезы -> компактная основа
```

Активные ячейки объединяются в прямоугольные, капсульные, эллиптические и срезанные зоны. Крупнейшие зоны становятся вырезами в квадратной, круглой или ромбической основе. Форма основы детерминирована буквой и поворотом семени; фон SVG образует негативное пространство.

## Кристалл

```text
буква -> нерегулярная треугольная сетка -> выборка покрытия граней -> цветные SVG-фасеты
```

Квадратная область разбивается на пары треугольников с детерминированным смещением внутренних вершин. Направление диагоналей и неровность сетки зависят от буквы. Грани сохраняются по среднему покрытию в центре и на ребрах, после чего масштабируются от центра для создания промежутков.

## Параметры

- `letter` - исходная буква.
- `font` - шрифтовой источник.
- `sectors` - количество радиальных секторов или модулей по стороне квадратной сетки.
- `scale` - размер буквы в скрытой маске.
- `offset` - вертикальное смещение буквы в скрытой маске.
- `density` - количество внутренних слоев.
- `rowWeight` - толщина кольцевых рядов.
- `cellGap` - векторный промежуток между ячейками.
- `ringTwist` - относительное вращение рядов; соседние кольца вращаются в разные стороны.
- `showGrid` - включает или скрывает чертежный слой сетки.
- `fillThreshold` - минимальная доля покрытия, после которой ячейка становится SVG path.
- `symmetry` - четыре или восемь отражений в квадратном калейдоскопе.

## Шаблоны сетки

- `brick` - ровная мозаика с шахматным смещением рядов.
- `galaxy` - больше ячеек к краю, активные повороты рядов.
- `sunburst` - крупные внешние лучи и более плотная середина.
- `mixed` - чередование широких и дробных рядов.
- `barcode` - плотные штриховые ряды, ближе к оп-арту.
- `pulse` - разорванная лучевая структура с более активным смещением.
- `burst` - трансформация как будто начинается из буквы и расходится радиальными фрагментами.
- `rosette` - более строгая модульная сетка для аккуратных знаков.
- `square-kaleidoscope` - квадратная модульная грамматика с 4x/8x отражением семени.
- `radial-emblem` - концентрическая грамматика с повторением двух дорожек по лепесткам.
- `modular-crest` - осевая макрогеометрия на основе квадратного отраженного семени.
- `radial-fingerprint` - радиальные модули по профилю пересечений лучей с буквой.
- `morph-kaleidoscope` - 4x/8x орбиты по глубине штрихов, направлениям и контрформам.
- `crest-mandala` - квадратное морфологическое ядро с радиальным поясом.
- `tectonics` - асимметричная сборка крупных зон из карты покрытия буквы.
- `skeleton` - связный граф локальных хребтов и узлов буквы.
- `packing` - детерминированная упаковка кругов, квадратов и капсул внутри маски.
- `armature` - направленные перекладины и узлы по локальной структуре штрихов.
- `isolines` - несколько эродированных контурных уровней буквы.
- `matrix` - геометрическая основа с негативными макрозонами буквы.
- `crystal` - нерегулярная треугольная сетка, отфильтрованная покрытием буквы.

## Текущий векторный поток

```text
буква -> шрифт -> alpha-маска -> выборка по площади -> фильтрация ячеек -> SVG path
```

Следующий возможный этап - получать контур буквы напрямую из glyph path. Для текущего модульного результата скрытая raster-маска не влияет на векторность финального файла.
