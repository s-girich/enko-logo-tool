# Алгоритм

## MVP

```text
буква -> скрытый raster canvas -> кольцевые ячейки -> локальные сдвиги, повороты и масштаб -> круговая маска -> квадратный знак
```

В этой версии браузер сначала рисует букву в скрытый canvas. На видимом canvas нет большой фоновой буквы: каждая ячейка радиальной сетки клипует собственный фрагмент исходного растра и рисует его с локальным смещением, поворотом и масштабом. Поэтому буква дробится и преломляется внутри сетки.

## Параметры

- `letter` - исходная буква.
- `font` - шрифтовой источник.
- `sectors` - количество радиальных секторов.
- `scale` - размер буквы внутри сектора.
- `offset` - расстояние буквы от центра.
- `refraction` - боковой сдвиг копий, создающий ощущение преломления.
- `density` - количество внутренних слоев.
- `rowWeight` - толщина кольцевых рядов.
- `cellGap` - промежуток между ячейками; увеличивает воздух и снижает эффект шредера.
- `ringTwist` - относительное вращение рядов; соседние кольца вращаются в разные стороны.
- `recognition` - сила перемешивания: ниже значение - сильнее дробление и поворот фрагментов.
- `showGrid` - включает или скрывает чертежный слой сетки.
- `renderMode` - выбирает между растровыми фрагментами и цельной заливкой ячеек.
- `fillThreshold` - порог, после которого ячейка закрашивается целиком.

## Шаблоны сетки

- `brick` - ровная мозаика с шахматным смещением рядов.
- `galaxy` - больше ячеек к краю, активные повороты рядов.
- `sunburst` - крупные внешние лучи и более плотная середина.
- `mixed` - чередование широких и дробных рядов.
- `barcode` - плотные штриховые ряды, ближе к оп-арту.
- `pulse` - разорванная лучевая структура с более активным смещением.
- `burst` - трансформация как будто начинается из буквы и расходится радиальными фрагментами.
- `rosette` - более строгая модульная сетка для аккуратных знаков.

## Целевое развитие

```text
буква -> шрифт -> glyph path -> нормализация -> секторная маска -> деформация ячеек -> булевы операции -> SVG path
```
